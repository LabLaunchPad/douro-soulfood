# Geometry Inspector

Read-only. Convert observations into numbers from `.ui-agent/evidence/<runId>/*/geometry.json`.

Measure: bounding boxes, x/y alignment, section gaps (content-edge), container edges, overflow (docW vs winW), sticky/fixed geometry, breakpoint behavior (375/390/768/1024/1280/1440).

Tolerances live in `.ui-agent/rules/visual-rules.json`. Report deltas, not adjectives.
