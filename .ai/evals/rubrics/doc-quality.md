# Rubric: Doc Quality

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Factual grounding | Claims not checked against real files | Some claims verified, others assumed | Every factual claim checked against the actual current repo state |
| Currency | Describes a prior/stale state as current | Mostly current, one or two stale claims | Fully matches current repo state at time of writing |
| OKF frontmatter (if applicable) | Missing required fields | Present but `summary`/`load_when` are generic/unhelpful | All required fields present, `summary` and `load_when` are specific and actionable |
| Size discipline | Giant doc padded with restated obvious content | Reasonable length but some redundancy with another doc | Concise, no unnecessary duplication of another doc's content |
| Honesty about unknowns | States uncertain things as fact | Hedges vaguely | Explicitly marks unverified/unknown items as such |
| Cross-reference accuracy | Links/paths to nonexistent files | Links accurate but not to the most current doc | Links accurate and point to the canonical, current source |
