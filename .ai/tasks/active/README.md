# Active Tasks

In-progress outcome tasks live here as OKF files (`{task-id}.okf.md`), one per task, using the templates in `.ai/tasks/templates/`. Move a task's file to `.ai/tasks/completed/` when finished, converting its frontmatter `status` to `active`→its outcome report status and filling in the evidence produced.
