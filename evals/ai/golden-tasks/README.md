# Golden Tasks

3 small, well-defined tasks any agent can use to prove basic competence in this repo, before being trusted with real work. Each defines objective/context required/expected output/acceptance criteria/evidence required.

| Task | File |
|---|---|
| 1. Documentation improvement | [golden-task-1-doc-improvement.md](./golden-task-1-doc-improvement.md) |
| 2. Design-token compliance audit | [golden-task-2-token-audit.md](./golden-task-2-token-audit.md) |
| 3. Benchmark report skeleton | [golden-task-3-benchmark-skeleton.md](./golden-task-3-benchmark-skeleton.md) |

Run one of these with a new/unfamiliar agent to check whether it follows `AGENTS.md`'s loop correctly before handing it real, higher-stakes work.
